# Mandelbro

A playful, editorial Enneagram field guide for the Mandelbro WhatsApp group. It translates the group’s score patterns into roles, pairwise dynamics, predictable failure modes, and practical rules for staying close.

The published site intentionally excludes the email addresses and test metadata visible in the original result screenshots.

## Local development

```bash
npm install
npm run dev
```

## Publishing

The main branch is deployed automatically to GitHub Pages. The same validated build can also be published through OpenAI Sites.
